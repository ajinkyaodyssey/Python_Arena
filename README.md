## How to Run
All code runs in GitHub Codespaces.
Open this repo, create a Codespace, then run any file:

```bash
python3 week1/saturday_project/library_system.py
python3 week1/day3/day3_challenge.py
python3 week2/day6/day6_challenge.py
```
